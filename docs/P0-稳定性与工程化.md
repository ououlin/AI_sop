### 1.1 异常处理中间件

**问题**：当前处理循环异常后仅打印日志，无法自动恢复，REST API 错误返回格式不统一。

**方案**：
- 添加全局异常处理中间件，捕获所有未处理异常
- 统一错误响应格式：`{"error": "...", "code": xxx, "detail": "..."}`
- 添加自定义异常类，支持业务错误码

**文件变更**：
- `backend/middleware/error_handler.py`（新建）
- `backend/main.py`（修改：注册中间件）

**代码示例**：
```python
# middleware/error_handler.py
from fastapi import Request, HTTPException
from fastapi.responses import JSONResponse
from logging import logger

async def error_handler(request: Request, exc: Exception):
    if isinstance(exc, HTTPException):
        return JSONResponse(
            {"error": exc.detail, "code": exc.status_code},
            status_code=exc.status_code,
        )
    logger.exception(f"未处理异常: {exc}")
    return JSONResponse(
        {"error": "服务器内部错误", "code": 500, "detail": str(exc)},
        status_code=500,
    )
```

### 1.2 处理循环守护机制

**问题**：处理循环崩溃后无法自动恢复，需要手动重启服务。

**方案**：
- 添加自动重启机制，崩溃后1秒内自动重启
- 在重启时重新初始化摄像头和检测器
- 增加最大重启次数限制，避免无限循环

**文件变更**：
- `backend/main.py`（修改：`_processing_loop` 函数）

**代码示例**：
```python
async def _processing_loop():
    max_restarts = 10
    restart_count = 0
    while True:
        try:
            # 当前处理逻辑...
            frame = camera.get_frame()
            if frame is None:
                await asyncio.sleep(0.03)
                continue
            
            annotated, hands = await loop.run_in_executor(None, detector.detect, frame)
            # ... 其余逻辑
            
        except asyncio.CancelledError:
            break
        except Exception as e:
            restart_count += 1
            if restart_count > max_restarts:
                logger.error("处理循环重启次数超限，停止运行")
                break
            logger.exception(f"处理循环异常，第{restart_count}/{max_restarts}次重启: {e}")
            await asyncio.sleep(1.0)
            # 重新初始化
            camera.stop()
            camera.start()
            restart_count = 0
```

### 1.4 日志规范

**问题**：当前日志格式不统一，不支持日志级别配置，无法输出到文件。

**方案**：
- 统一日志格式，支持 JSON 格式输出
- 支持日志级别配置（DEBUG/INFO/WARN/ERROR）
- 添加日志文件输出，按日期滚动

**文件变更**：
- `backend/logging_config.py`（新建）
- `backend/main.py`（修改：使用新的日志配置）

**代码示例**：
```python
# logging_config.py
import logging
import os
from logging.handlers import RotatingFileHandler

def setup_logging():
    log_level = os.getenv("LOG_LEVEL", "INFO").upper()
    log_dir = os.path.join(os.path.dirname(__file__), "logs")
    os.makedirs(log_dir, exist_ok=True)
    
    logger = logging.getLogger()
    logger.setLevel(log_level)
    
    formatter = logging.Formatter(
        "%(asctime)s [%(levelname)s] %(name)s: %(message)s",
        datefmt="%Y-%m-%d %H:%M:%S",
    )
    
    # 控制台输出
    console_handler = logging.StreamHandler()
    console_handler.setFormatter(formatter)
    logger.addHandler(console_handler)
    
    # 文件输出（滚动）
    file_handler = RotatingFileHandler(
        os.path.join(log_dir, "ai_sop.log"),
        maxBytes=10 * 1024 * 1024,  # 10MB
        backupCount=5,
        encoding="utf-8",
    )
    file_handler.setFormatter(formatter)
    logger.addHandler(file_handler)
```
