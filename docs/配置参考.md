# 配置参考

> 所有配置通过环境变量或 `backend/.env` 提供，模板见 `backend/.env.example`。
> 修改后重启后端生效；标「运行时可改」的项支持接口热更新。

## 1. 服务与数据库

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `HOST` | `0.0.0.0` | 监听地址 |
| `PORT` | `8000` | 监听端口 |
| `CORS_ORIGINS` | dev 默认 | 允许跨域来源，逗号分隔 |
| `DATABASE_URL` | `sqlite:///backend/data/ai_sop.db` | 数据库连接串，支持 PostgreSQL |
| `DEFAULT_TENANT_CODE` | `default` | 默认租户编码，存量数据与后台任务归属 |
| `JWT_SECRET` | 随机生成 | JWT 签名密钥，**生产必须固定配置** |
| `JWT_EXPIRE_HOURS` | `24` | 登录有效期（小时） |
| `COOKIE_SECURE` | `false` | HTTPS 部署时设为 `true` |
| `LOG_LEVEL` | `INFO` | 日志级别 |

## 2. 摄像头与视频

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `CAMERA_INDEX` | `0` | 摄像头索引（运行时可改：`POST /camera/switch`） |
| `CAMERA_BACKEND` | `MSMF` | OpenCV 后端，Windows 推荐 MSMF |
| `CAMERA_WIDTH` / `CAMERA_HEIGHT` / `CAMERA_FPS` | `640` / `480` / `30` | 采集参数 |
| `JPEG_QUALITY` | `60` | 视频帧 JPEG 质量 |
| `STATUS_INTERVAL` | `0.2` | 状态推送节流（秒） |

## 3. 物体检测

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `OBJECT_DETECTION_ENABLED` | `true` | 是否启用物体检测；未安装 `ultralytics` 时降级为颜色追踪 |
| `OBJECT_DETECTION_CONFIDENCE` | `0.5` | 置信度阈值 |
| `YOLO_MODEL_PATH` | - | YOLOv8 权重路径 |
| `OBJECT_CLASS_ALIASES_JSON` | - | 业务类别别名映射，JSON 字符串 |

## 4. 告警

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ALARM_WEBHOOK_URL` | - | 告警 Webhook（企业微信 / 钉钉） |
| `ALARM_LEVEL_FILTER` | `warning` | Webhook 告警级别过滤 |
| `ALARM_SOUND_ENABLED` | `true` | 是否播放声音告警 |

## 5. 多工位与租户

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `STATION_ID` | `W-001` | 当前工位 ID |
| `STATION_NAME` | `工位1` | 当前工位名称 |
| `STATION_API_KEY` | - | 工位上报共享密钥，**生产必须配置** |
| `CENTRAL_SERVER_URL` | - | 中央聚合服务地址 |
| `ENABLE_LOCAL_AGGREGATION` | `true` | 是否在本进程挂载聚合路由 |
| `STATION_REPORT_TO_SELF` | `false` | 自调用时是否仍上报 |
| `PLATFORM_ADMIN_USERNAME` | `platform` | 平台管理员账号（配置密码后自动创建） |
| `PLATFORM_ADMIN_PASSWORD` | - | 平台管理员密码；留空则不创建 |

## 6. 区域标定

区域通过 `POST /sop/zones` 保存，**立即生效**并持久化到 `data/zones.json`，重启后自动加载；文件损坏时回落到 `config.py` 中的默认区域。

## 8. 开放平台

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `OPEN_API_RATE_LIMIT_PER_MIN` | `120` | 每个 API Key 每分钟请求上限（进程内计数） |

## 7. 部署形态与配置组合

| 形态 | 关键配置 |
|------|----------|
| 单机部署（默认） | `ENABLE_LOCAL_AGGREGATION=true`；不设 `CENTRAL_SERVER_URL` |
| 多工位（工位端） | `ENABLE_LOCAL_AGGREGATION=false`；`CENTRAL_SERVER_URL=http://中央服务:8000`；`STATION_ID` 每个工位唯一 |
| 多工位（中央端） | `ENABLE_LOCAL_AGGREGATION=true`；配置 `STATION_API_KEY` |
| SaaS 多租户 | `DATABASE_URL` 指向 PostgreSQL；配置 `PLATFORM_ADMIN_PASSWORD` 开通租户 |

详细部署步骤见 [部署指南](部署指南.md)。
