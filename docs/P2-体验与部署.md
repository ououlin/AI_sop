### 3.1 物体检测能力（识别精度核心升级）

**问题**：当前仅靠"手势+区域"二元判定，工人手部被遮挡时失效，相似手势无法区分（拿取vs放置），误判率高，无法满足生产环境要求。

**方案**：
- 引入轻量级物体检测模型（YOLOv8-nano 或 MobileNet-SSD）
- 检测关键物体：电路板、元件、工具、成品
- 步骤判定条件升级为"手+目标物体同时在目标区域"
- 支持自定义物体类别训练（提供标注工具链）

**文件变更**：
- `backend/detectors/object_detector.py`（新建）
- `backend/detectors/model_loader.py`（新建）
- `backend/step_recognizer.py`（修改：融合物体检测结果）
- `backend/models.py`（修改：增加 ObjectDetection 数据模型）
- `backend/config.py`（修改：增加检测模型配置）

**技术方案**：
```python
# detectors/object_detector.py
from ultralytics import YOLO
from typing import List
from models import ObjectDetection, BoundingBox

class ObjectDetector:
    def __init__(self, model_path: str = "yolov8n.pt", confidence: float = 0.5):
        self.model = YOLO(model_path)
        self.confidence = confidence
        # 自定义类别映射（支持用户扩展）
        self.custom_classes: Dict[int, str] = {}

    def detect(self, frame) -> List[ObjectDetection]:
        results = self.model(frame, conf=self.confidence, verbose=False)
        detections = []
        for r in results:
            for box in r.boxes:
                cls_id = int(box.cls[0])
                detections.append(ObjectDetection(
                    class_name=self._get_class_name(cls_id),
                    confidence=float(box.conf[0]),
                    bbox=BoundingBox(
                        x1=float(box.xyxy[0][0]),
                        y1=float(box.xyxy[0][1]),
                        x2=float(box.xyxy[0][2]),
                        y2=float(box.xyxy[0][3]),
                    ),
                ))
        return detections
```

```python
# step_recognizer.py 修改：融合物体检测
def update(self, hands: List[HandResult], objects: List[ObjectDetection] = None) -> bool:
    if self.is_completed():
        return True
    
    step = self.current_step()
    if not step:
        return False
    
    # 原有手势+区域判定
    hand_match = self._check_hand_condition(hands, step)
    
    # 新增：物体检测判定（如果步骤配置了目标物体）
    object_match = True
    if step.required_objects:
        object_match = self._check_object_condition(objects, step)
    
    # 双重判定：手势+物体都满足才计为匹配
    matched = hand_match and object_match
    self._update_match_state(matched)
    return True
```

### 3.2 异常告警与错误状态机

**问题**：当前只有 `待执行→进行中→已完成` 三态，无法处理步骤跳过、顺序错误、超时等生产场景关键异常。

**方案**：
- 状态机扩展为7态：`pending / in_progress / completed / skipped / error / timeout / unauthorized_skip`
- 实时异常检测：步骤顺序错误、超时未完成、违规操作
- 多渠道告警：屏幕弹窗、声光信号、Webhook推送（企业微信/钉钉）
- 告警分级：提示/警告/严重

```python
# models.py
class StepStatus(str, Enum):
    PENDING = "pending"
    IN_PROGRESS = "in_progress"
    COMPLETED = "completed"
    SKIPPED = "skipped"                    # 手动跳过（授权）
    ERROR = "error"                        # 操作错误
    TIMEOUT = "timeout"                    # 超时未完成
    UNAUTHORIZED_SKIP = "unauthorized_skip" # 未授权跳过

class AlarmLevel(str, Enum):
    INFO = "info"
    WARNING = "warning"
    CRITICAL = "critical"

class Alarm(BaseModel):
    id: str
    level: AlarmLevel
    type: str          # timeout / sequence_error / unauthorized_skip / object_missing
    step_id: Optional[int]
    message: str
    timestamp: datetime
    acknowledged: bool = False
```

```python
# alarm/alarm_manager.py
class AlarmManager:
    def __init__(self):
        self.notifiers: List[Notifier] = []
        self.history: List[Alarm] = []
    
    def check_anomalies(self, recognizer: StepRecognizer, elapsed: float):
        """每次状态更新时检查异常"""
        current_step = recognizer.current_step()
        if not current_step:
            return
        
        # 超时检查
        if elapsed > current_step.timeout_sec:
            self.trigger(Alarm(
                level=AlarmLevel.WARNING,
                type="timeout",
                step_id=current_step.step_id,
                message=f"步骤 [{current_step.name}] 超时 {elapsed:.0f}秒",
            ))
        
        # 顺序错误检查（手在错误区域且手势匹配）
        # ... 见 step_recognizer 集成
    
    def trigger(self, alarm: Alarm):
        self.history.append(alarm)
        for n in self.notifiers:
            asyncio.create_task(n.notify(alarm))
```

```python
# agent/station_agent.py
class StationAgent:
    """工位Agent：本地下行识别 + 上行数据同步"""
    def __init__(self, station_id: str, central_url: str):
        self.station_id = station_id
        self.central_url = central_url
        self.camera = CameraService()
        self.detector = HandDetector()
        self.object_detector = ObjectDetector()
        self.recognizer = StepRecognizer()
        
    async def start(self):
        """启动Agent：本地识别循环 + 心跳上报"""
        await asyncio.gather(
            self._processing_loop(),    # 本地识别
            self._heartbeat_loop(),      # 心跳保活
            self._data_sync_loop(),      # 数据同步
        )
    
    async def _data_sync_loop(self):
        """每秒上报状态到中央服务"""
        while True:
            payload = {
                "station_id": self.station_id,
                "status": self.recognizer.get_status(),
                "current_step": self.recognizer.current_step(),
                "alarms": self.alarm_manager.get_recent(),
                "timestamp": datetime.now().isoformat(),
            }
            try:
                await httpx.post(f"{self.central_url}/api/v1/station/report", json=payload)
            except Exception:
                pass  # 中央服务不可用时本地继续运行
            await asyncio.sleep(1.0)
```

### 3.4 权限系统与用户管理

**问题**：完全无权限控制，无法区分操作员/管理员/查看者，无法满足工厂管理需求。

**方案**：
- JWT认证 + 角色权限（RBAC）
- 三种角色：operator（操作员）/ supervisor（线长）/ admin（管理员）
- 操作员：只能执行SOP、查看本工位
- 线长：查看产线看板、处理告警、导出报告
- 管理员：管理SOP、配置工位、管理用户
